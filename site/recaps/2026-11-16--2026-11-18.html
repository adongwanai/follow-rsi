Recursive Self-Improvement on a Budget: Scoring Code Edits Before They Run

A linear readout, frozen after fitting, scores scaffold-code edits before execution, followed by candidate selection and retention using steering-split feedback. In the GPT-4o experiment, returned nodes score 87.0% on held-out HumanEval+, versus 84.2% for the parent-rate ablation; these percentages are scores, not proportions of nodes returned.

Multimodal Filesystem Memory For Long-Horizon Embodied Agents

Multimodal Filesystem Memory 允许 Agent 根据执行结果创建、修改和停用文本或可执行 procedure，并在后续生命与任务中复用。Harness 证据来自可修改的过程技能分支；位置笔记和工作记忆仍属于记忆内容。这些技能复用结果不代表所有任务成功率提高，也不意味着每个存储过程都有益或技能库越大越好。

Multimodal Filesystem Memory lets an agent create, revise, and disable textual or executable procedures using execution feedback, then reuse them in later lives and tasks. These skill-reuse results do not establish a success-rate improvement across all tasks, nor do they show that every stored procedure is beneficial or that a larger skill library is always better.
