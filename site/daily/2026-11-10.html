EmoHarness

EmoHarness: Boosting Multimodal Emotion Understanding with Meta-Harness Evolving

EmoHarness让Builder依据冻结学生模型的失败轨迹修改提示、配置和受限验证代码，用独立验证集决定是否替换当前Harness，并将采用版本留给后续改进轮。主要收益来自音频证据，演化增量未通过多重比较校正；人工开发曾查看部分评测项，因此不能将全部评测称为从未触碰的留出集。

EmoHarness uses a Builder to revise prompts, settings and restricted verification code from a frozen student model’s failure traces. A separate validation split decides whether a candidate replaces the current Harness for later rounds. Most gains come from audio evidence, and the incremental evolution gains do not survive multiple-comparison correction. Human developers inspected some evaluation items, so the evaluation is not an untouched holdout.
