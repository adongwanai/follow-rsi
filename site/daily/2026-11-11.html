1.1 搜索与演化主线1.1 Search & evolution (frozen model)

Verify by Doing

Verify by Doing: Co-Evolving Agent Execution and Evaluation without External Feedback

通过工具执行与核查共同修改 Actor 和 Evaluator 的指令、评判规则及技能，保留到后续改进轮次；Actor 的采纳须由其自身的新输出支持。模型权重固定，独立任务之间重置 Harness 与历史，跨任务迁移及长期持续改进尚未验证。

Uses tool execution and inspection to revise Actor and Evaluator instructions, rubrics and skills, retaining them across improvement rounds; Actor adoption requires support from its own fresh output. Model weights stay fixed. Harnesses and history reset between independent tasks, so cross-task transfer and sustained long-term improvement remain untested.

三、组件级进化3. Component-level evolution (skills, memory, context, interfaces)

World In-Context Learning for Agentic Robot Manipulation

RoboScript 在任务学习前把汇集的示范拆为动作片段，将现有接口无法覆盖的缺口交给 coding agent 编写环境技能。独立 driver 回放、检查跨布局复用并复查新增技能的得失，按覆盖反馈迭代后冻结技能库，供后续任务调用。这里仅将可执行工具技能的构建与筛选闭环纳入 Harness；普通 Task Memory 内容更新另计。论文未单独量化技能构建的贡献，部署中遇到失败再持续生成新技能仍是未来工作。

Before task learning, RoboScript segments the collected demonstrations and asks a coding agent to write environment-specific skills for gaps in the existing action interface. An independent driver replays the skills, checks transfer across layouts, and rechecks gains against regressions. Coverage feedback drives further rounds before the skill library is frozen for later tasks. Inclusion is limited to this executable tool-skill construction and selection loop, separate from ordinary Task Memory content updates. The paper does not isolate the contribution of skill construction, and continual failure-driven skill creation during deployment remains future work.

HyperSkill

HyperSkill: Training-Free Omnimodal GRPO via Hypergraph-Indexed Skill-Library Evolution

根据训练轨迹的失败类型组合并保留协议指令，冻结后在测试问题间复用；技能库另按反馈演化。Harness 纳入限于协议提示组件，模板和执行机制固定，多数数据集关闭检索技能注入，不能把整体收益全归超图技能演化。反事实准入使用模型判断。

Compiles and retains protocol instructions from failure types in training trajectories, then freezes them for reuse across test questions; a skill library also evolves from feedback. Harness inclusion is limited to the protocol-prompt component. Templates and the execution mechanism stay fixed, retrieved skills are disabled on most datasets, and overall gains cannot all be attributed to hypergraph skill evolution. Counterfactual admission uses model judgments.

RSI-PDEbench

RSI-PDEbench: A Benchmark for Self-Improving Agents in PDE Solving

执行与验证反馈共同筛选数值求解器及后续调查指令，并把通过的指令保留到下一轮；模型与可执行监督器固定。纳入依据是指令策略迭代，求解器本身属于任务产物。作者已接触测试结果，最终程序变好不等于改进器变强。

Execution and validation feedback select solver edits together with instructions for subsequent investigation, retaining accepted instructions for later rounds while the model and executable supervisor stay fixed. Inclusion rests on instruction-policy evolution; the solver is a task artifact. Developers have seen test results, and a better final program does not establish a better improver.

AskALCF

AskALCF: A Self-Improving Agentic System for Intelligent HPC User Support

人工专家按预定目标与控制案例迭代诊断规则、judge 技能和覆盖门，保留通过检查的 Harness 版本，并用按会话分开的评估集检查。属于人工引导的 Harness 改进评测；自动生成的知识变更尚未获批合并到已部署语料并重建索引，不能称生产系统已自主修复。

Human experts iteratively revise diagnostic rules, judge skills and an override gate against prespecified target and control cases, retaining accepted Harness versions and checking a session-disjoint evaluation split. This is a human-guided Harness-improvement evaluation. No automatically generated knowledge change has been approved, merged and re-indexed in the deployed corpus, so it does not establish autonomous production repair.
