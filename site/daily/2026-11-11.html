三、组件级进化3. Component-level evolution (skills, memory, context, interfaces)

World In-Context Learning for Agentic Robot Manipulation

RoboScript 在任务学习前把汇集的示范拆为动作片段，将现有接口无法覆盖的缺口交给 coding agent 编写环境技能。独立 driver 回放、检查跨布局复用并复查新增技能的得失，按覆盖反馈迭代后冻结技能库，供后续任务调用。这里仅将可执行工具技能的构建与筛选闭环纳入 Harness；普通 Task Memory 内容更新另计。论文未单独量化技能构建的贡献，部署中遇到失败再持续生成新技能仍是未来工作。

Before task learning, RoboScript segments the collected demonstrations and asks a coding agent to write environment-specific skills for gaps in the existing action interface. An independent driver replays the skills, checks transfer across layouts, and rechecks gains against regressions. Coverage feedback drives further rounds before the skill library is frozen for later tasks. Inclusion is limited to this executable tool-skill construction and selection loop, separate from ordinary Task Memory content updates. The paper does not isolate the contribution of skill construction, and continual failure-driven skill creation during deployment remains future work.
