Does a Self-Learning Migration Agent Learn? An Audited Evaluation of Evidence-Graded Experience Memory for Oracle-to-PostgreSQL Migration

迁移实验中的人工监督循环以预先写定的检查条件和 Oracle 执行结果筛选提示段与 Harness 修复，保留到后续版本；与记忆和策略 ranker 实验分开。同一语料反复参与调试且规模变化，原始工件未公开，不能当作自主改进或独立留出集验证。

A human-supervised migration study selects prompt paragraphs and Harness fixes using prespecified checks and Oracle execution results, retaining revisions across versions; memory and strategy-ranker experiments are separate. The same corpus is repeatedly used for debugging and changes in size; raw artifacts remain internal, so this is not evidence of autonomous improvement or independent holdout validation.

Small Language Models for Inference-Capability Routing

Small Language Models for Inference-Capability Routing: Effects of Model Capacity and Prompt Optimization on Downstream Quality and Efficiency

用反馈优化推理、检索和工具能力的路由指令，再将保留的提示用于后续查询，比较路由质量与下游表现。部分下游数据与前序数据重叠且标签事后修正；所列节省不含路由器开销，两部分测量环境不同，不能当作端到端成本或延迟收益。

Optimizes capability-routing instructions for reasoning, retrieval and tools from feedback, then reuses the retained prompts on later queries to study routing and downstream behavior. Some downstream data overlap earlier data and labels were revised after analysis. Reported savings omit router overhead and the measurements use different environments, so they are not end-to-end cost or latency gains.

原始发表Published2026-11-12

Evidence-Governed Adoption of Self-Generated Updates in Autonomous AI Agents

提出自生成提示、工具和工作流配置的持久准入理论：先冻结候选，再以新鲜审计样本和预定指标决定采纳，并约束相对参考版本的退化。证据来自合成统计实验，尚无真实 Agent 实证；保证受抽样、评估有效性与目标分布假设限制。

Develops a theory for persistent adoption of generated prompt, tool and workflow configurations: freeze a candidate, audit it with fresh observations and prespecified metrics, and constrain degradation relative to a reference. Evidence comes from synthetic statistical experiments, not a real-agent study; guarantees depend on sampling, evaluation validity and target-distribution assumptions.
