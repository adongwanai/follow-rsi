**一句话**：Skill^{infty} 把技能优化做成递归自我改进，meta agent 按 meta-skill 优化任务技能，并用同一流程改写 meta-skill 本身，该 meta-skill 与任务技能解耦、可在多个任务上精炼后跨域复用；在 83 个 SkillsBench 任务上通过率为 60.7%，高于人工整理技能的 56.4% 和 SkillEvolver 的 54.5%。

**Summary**: Skill^{infty} makes skill optimization recursive self-improvement: meta agent optimizes task skills via meta-skill and rewrites meta-skill itself by the same process; decoupled from task skills, refined on multiple tasks and cross-domain reused.
