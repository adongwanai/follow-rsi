Figure 3: Image editing and interleaved generation. Editing pairs: source (left), result (right). Contents 1 Introduction Multimodal understanding and visual generation place complementary
demands on a model. Understanding requires interpreting visual inputs,
whereas generation requires synthesizing visual content from text or
visual conditions. Combining autoregressive language modeling with
continuous visual prediction has become a central approach to
unification, as demonstrated by Transfusion and
Show-o2 ( Zhou et al., 2024 , Xie et al., 2025 ) . BAGEL brings
understanding, generation, and editing into a shared multimodal sequence
and backbone through modality-specific transformer
parameters ( Deng et al., 2025 ) , while SenseNova-U1 further explores native
unified representations and interleaved vision-language
generation ( Diao et al., 2026 ) . In interleaved sequences,
completed visual outputs can in turn serve as context for subsequent
text and image predictions, linking understanding and generation
across successive outputs. UniAR ( Peng et al., 2026 ) enables such context reuse through a shared discrete visual
tokenizer, allowing generated tokens to become context without
re-encoding the image. In continuous visual
generation, however, context reuse must account for the iterative
denoising process. Consider a model that generates an image, explains it,
and then edits it in response to a new instruction. During denoising,
the image is represented by a noisy target; once generated, its clean
representation becomes context for subsequent predictions. Retaining
intermediate denoising states would expose later predictions to transient
noise, whereas discarding visual history would remove the reference
needed for consistent editing. Unified modeling therefore requires
separating noisy prediction targets from reusable clean visual context. High-resolution images and multi-image sequences increase the
visual-token workload of unified multimodal models. Hybrid attention
combines full attention for explicit token
interactions ( Vaswani et al., 2017 ) with recurrent linear attention
that propagates context through a persistent state at a cost linear
in sequence length ( Katharopoulos et al., 2020 , Yang et al., 2025b ) .
Kimi Linear and Olmo Hybrid explore layer-wise combinations of these
operators in language
modeling ( Kimi Team et al., 2025b , Merrill et al., 2026 ) , and Qwen3.5
provides a backbone combining full attention with GatedDeltaNet
layers ( Qwen Team, 2026 ) . We investigate how full and
linear attention interact across layers to support causal text
prediction and iterative visual denoising within a unified model,
and characterize its multimodal capabilities and computational
trade-offs. We present UniSpark , a unified model for multimodal understanding and visual generation. The UniSpark-9B
configuration has approximately 9B parameters in each of its
understanding and generation branches. Building on the
Mixture-of-Transformer-Experts formulation ( Liang et al., 2025 , Deng et al., 2025 ) and the Qwen3.5 hybrid-attention backbone ( Qwen Team, 2026 ) ,
UniSpark combines expert routing and hybrid attention in a Hybrid MoT Architecture . Text and semantic visual features use the understanding expert, whereas VAE latents use the generation expert. Within each multimodal sequence, the experts exchange information through full attention and shared recurrent states. Autoregressive text prediction and visual flow matching ( Lipman et al., 2023 ) jointly support multimodal understanding, text-to-image generation, reference-conditioned image editing, and interleaved prediction within the same model. The information-flow design separates private prediction targets from public context . A noisy visual block reads its public prefix but is hidden from later blocks. Full-attention layers implement this rule with block visibility masks. Linear-attention layers process the block recurrently, but discard its private state and convolution-history updates after local computation on a noisy block.
Clean visual representations instead update the public context. During training, this context is obtained from ground-truth
images using teacher forcing ( Williams & Zipser, 1989 ) ; at inference,
it is built by encoding completed model outputs. The training data span visual understanding, image generation and editing, interleaved sequences, and text-only language modeling. Understanding data cover captioning, visual question answering, OCR, GUI tasks, and grounding. Task-specific adapters map each data type to a common sequence plan. Online packing combines samples within token budgets while preserving
sample boundaries, within-sample block structure, and supervision locations. Full-attention masks prevent cross-sample visibility, while linear-attention layers reset their recurrent state and convolution history at sample boundaries.
The selected sources contain 159.7M generation samples and 213.4M understanding samples, including 10.0M OCR and 4.5M grounding samples, as well as 624.8K interleaved sequences. The data extend beyond image–caption pairs to support general semantic learning, specialized visual tasks, and the modeling of state changes over time. Training proceeds through four main stages. The Joint Multimodal Foundation stage trains the model on text prediction, visual understanding, and low-resolution image generation. The Progressive Resolution Scaling and High-Resolution Refinement stages extend image generation to 2K while retaining understanding supervision. Supervised Capability Refinement (SFT) then improves understanding accuracy, instruction adherence, image-generation quality, and editing consistency.
Following these four stages, we further adapt the model to video generation and editing using a mixture of image and video data. Our main contributions are: • Hybrid MoT Architecture. We combine token-type expert
routing with full attention and GatedDeltaNet linear attention in a
shared backbone.
This hybrid design combines explicit multimodal interactions with
efficient context propagation across long visual sequences. • Context handling for interleaved prediction. We
introduce a blockwise information-flow protocol that keeps noisy
visual targets private while allowing clean visual content to
condition later text and visual outputs under both attention operators. • Unified data interface and progressive training. We map understanding, generation, editing, interleaved, and
text-only data to task-specific sequence plans, then pack them
through a shared interface. A four-stage training curriculum yields
a single model for visual understanding, 2K image generation,
editing, and interleaved prediction. 2 Related Work 2.1 Unified Multimodal Understanding and Generation Unified multimodal models use a shared model
to understand and generate visual content. Transfusion combines
autoregressive text prediction with image diffusion ( Zhou et al., 2024 ) .
Mixture-of-Transformers uses separate parameters for each modality while
sharing attention across them ( Liang et al., 2025 ) . BAGEL builds on
this approach and trains a unified model on interleaved multimodal
data ( Deng et al., 2025 ) . These works form the basis of our shared architecture
and joint text and visual training objectives. Other approaches explore alternative visual representations and broader task coverage. Tuna-2 uses direct pixel-patch embeddings in
place of separate visual encoders ( Liu et al., 2026 ) . SenseNova-U1
supports understanding, image generation, and interleaved vision-language
generation with dense and MoE backbones ( Diao et al., 2026 ) .
SenseNova-Vision handles different vision tasks through text, image, or
mixed outputs without separate prediction heads ( Han et al., 2026 ) .
UniSpark uses semantic visual features and VAE latents, and studies
how hybrid attention lets these representations share context. Sharing visual context also allows one
output to guide the next. UniAR uses a shared discrete visual tokenizer, allowing generated visual tokens to be reused directly as context without re-encoding the image ( Peng et al., 2026 ) . Context Unrolling studies reasoning through
text, images, video, and geometry before making
predictions ( Yang et al., 2026 ) . UniSpark addresses context reuse in continuous visual generation by separating noisy targets from clean context through attention masks and recurrent-state retention rules. A model that supports both tasks does not
necessarily improve one task by learning the other. VGAU-Diag tests when
generated visual aids help understanding and finds cases where models
fail to use even correct visual aids ( Zhu et al., 2026 ) . Wu et al. examine
how understanding and generation help each other at the representation,
task, and system levels, and identify task specialization and shared
knowledge as important factors ( Wu et al., 2026 ) . These studies highlight the distinction between joint task support and cross-task synergy. 2.2 Efficient and Hybrid Attention Mechanisms Recurrent attention stores past information
in a state that is updated as tokens are processed. Gated DeltaNet uses
adaptive forgetting and delta-rule updates ( Yang et al., 2025b ) .
Kimi Linear adds finer gating through Kimi Delta Attention and combines
it with Multi-Head Latent Attention across layers ( Kimi Team et al., 2025b ) .
Gated DeltaNet-2 uses separate erase and write gates for each memory
channel ( Hatamizadeh et al., 2026 ) . These methods control how memory is
updated. These methods govern token-level memory updates; UniSpark additionally enforces block-level retention rules to prevent noisy-target updates from entering public context. Hybrid backbones combine recurrent layers
with full attention. UniSpark starts from Qwen3.5, which combines
GatedDeltaNet and full-attention layers ( Qwen Team, 2026 ) .
Olmo Hybrid studies this combination through theory and controlled
language-modeling experiments ( Merrill et al., 2026 ) . In vision,
SoLA-Vision studies how to arrange linear and softmax attention across
layers ( Li et al., 2026 ) . SANA-Video 2.0 combines gated linear
attention, periodic softmax layers, and attention residuals for video
diffusion ( Chen et al., 2026 ) . Our work explores hybrid attention
in a model trained jointly for multimodal understanding and generation. Attention types can also be combined within
a layer. HydraHead assigns full and linear attention to different heads,
keeps full attention for heads important to retrieval, and normalizes
their outputs before combining them ( Tan et al., 2026 ) .
UniSpark combines the two attention types across layers. Reusing
context also requires careful state handling: HARTS studies shared
prefixes in branching agent rollouts, including state transfers and
activation recomputation ( Meng et al., 2026 ) . Although HARTS focuses on
agent reinforcement learning, it illustrates the need to coordinate
recurrent states when computation branches or context is reused. 3 Model Design UniSpark uses a Hybrid MoT Architecture for
multimodal understanding and generation. Building on the multimodal
Mixture-of-Transformer-Experts (MoT) formulation of
BAGEL ( Deng et al., 2025 ) and the hybrid attention backbone of
Qwen3.5 ( Qwen Team, 2026 ) , the architecture combines
specialized understanding and generation experts with a layer-wise
mixture of full attention and recurrent linear attention in one shared
backbone. UniSpark-9B uses approximately 9B parameters per branch,
with the 9B designation referring to the per-branch backbone size rather
than the total model size. Causal language prediction and iterative visual generation impose
different requirements on information flow: text predicts the next token
from its prefix, visual generation refines a block of noisy latent tokens,
and subsequent outputs must condition on completed visual content without
inheriting intermediate noise states. The experts exchange context through
full and recurrent linear attention, with explicit rules governing context
reuse across visual outputs. Fig. 4 summarizes this organization. Figure 4: Hybrid MoT Architecture of UniSpark. Token-type routing selects understanding or generation parameters,
while full-attention and recurrent linear-attention layers exchange

visual blocks, together with conversation roles, media boundaries, and
supervision indicators. Text is mapped through the language embedding
layer. Images and video frames used for understanding are encoded by the
Qwen3.5 vision encoder, whose output features are mapped into the language
model’s hidden space. Images and videos used as generation targets or clean
context are both encoded by the Wan2.2 VAE ( Wan Team, 2025 ) ; the resulting latents are patchified and
mapped to the backbone hidden space through a latent adapter. Semantic
features provide an understanding-oriented representation, while VAE
latents provide the continuous representation used for visual prediction.

Counts refer to indexed samples; byte-identical Ditto shards are counted once. 4.1 Multimodal Understanding The understanding mixture comprises image captioning, knowledge-oriented
visual question answering, OCR, GUI understanding, and visual grounding.
These correspond to separate sampling groups, allowing broad semantic
supervision and specialized visual tasks to be balanced independently.
Captioning supplies descriptions of image content, while visual questions
connect image evidence to a requested answer. The specialized groups cover
complementary aspects of visual understanding: • OCR and document content. Image-conditioned text
supervision emphasizes reading visible text and relating it to the
surrounding visual context. • GUI understanding. Interface images and associated
instructions connect language to visual elements in structured screens. • Visual grounding. Localization-oriented examples connect
referring expressions to spatially specified visual content. • Visual knowledge and question answering. Image-grounded
questions and responses broaden semantic coverage beyond captioning. Images are processed by the understanding frontend with
aspect-ratio-aware resizing, patch/merge alignment, and a pixel budget.
The lower-resolution mixtures use a target long-edge setting of 384;
expanded mixtures use a target setting of 980, aligned to 960 by the
spatial factor of 32. These transforms are independent of the generation
resolution. Conversation roles and supervision masks identify the assistant
text to predict, while the image remains an input condition. 4.2 Image Generation The generation stream provides images and associated text conditions through
a dedicated image-data reader. Each example is converted into conditioning
text and a target VAE latent sequence. The target receives flow-matching
supervision, while text provides its semantic condition. Generation is
sampled separately from understanding and editing, enabling the mixture to
control their relative training exposure. Generation data follow the resolution curriculum rather than a single
fixed-size preprocessing rule. The foundation setting uses 256-scale
images; resolution scaling introduces a 512-scale setting; high-resolution
refinement extends the range through 1024-scale settings and up to 2K.
Images retain their aspect-ratio structure subject to resize, stride, and
pixel-budget constraints, so image dimensions vary within each scale.

Online packing combines task-specific samples within a token budget while preserving sample isolation and the public/private boundaries required by hybrid attention. Unified sequence assembly. The task adapters convert samples from different tasks into a common sequence
plan containing text roles, media identities, attention-block types, and
supervision locations. Packing concatenates multiple examples while
retaining their individual sequence boundaries and within-example block
structure. Text labels and visual targets are gathered through separate
loss indices, so conditioning content can share the input sequence without
receiving a prediction loss. For interleaved samples, the complete sequence
of transitions and images remains within the same example; packing does
not turn successive editing steps into unrelated image–text pairs. Online token-budget packing. The loader starts each pack by inserting eligible examples from mandatory
task groups. It then selects additional examples according to normalized
group weights, using modality-aware token estimates to account for text
and visual content. A soft token target determines when a pack is normally
produced, while a per-example threshold rejects oversized samples and a
separate packed-token budget guides additional insertions. Examples that
do not fit can be stored in a fixed-size buffer for later use. The loader reuses buffered
examples in first-in, first-out order when the current pack is below a
configured occupancy threshold. This online policy accommodates the
changing token costs of image resolution, aspect ratio, and interleaved
sequence length without requiring a fixed number of images per batch.
The final accepted example or mandatory insertion can exceed the nominal
token budget.

(SFT) . This organization separates learning a shared multimodal backbone,
increasing spatial detail, extending high-resolution generation, and
refining task performance. Tab. 2 summarizes the
four stages. The backbone retains the joint text and visual objectives in Sec. 3.3 throughout this design. 5.1 Joint Multimodal Foundation The foundation stage trains the hybrid MoT backbone with a low visual token
budget. Text and semantic visual tokens use the understanding expert, while
VAE latent tokens use the generation expert. Language modeling and visual
flow matching provide direct supervision for the two output types. The 256-scale setting keeps visual targets relatively short while
establishing interactions between the two experts. The language backbone, vision encoder, and expert
branches and adapters are trained jointly, while the VAE remains frozen.
The stage’s purpose is to establish the shared prediction interface before
increasing the spatial sequence length. 5.2 Progressive Resolution Scaling The resolution-scaling stage increases generation to a 512-scale setting
while retaining the same token roles and loss definitions. More latent
patches represent each image, allowing training to cover finer spatial
detail. Understanding inputs have an independent resolution budget, so
higher-resolution generation does not require every semantic condition to
expand at the same rate. Interleaved sequences can continue to contribute text and visual targets in
this stage. Clean representations of earlier images remain public context,
while noisy prediction blocks remain private. This exposes hybrid attention
to both longer visual blocks and dependencies across multiple outputs. and optimizer states across GPUs. Decoder-layer and vision-encoder
activation checkpointing reduce memory use through recomputation ( Chen et al., 2016 ) .
These methods support training with longer visual sequences. Attention execution for packed multimodal sequences. Variable-length attention backends directly use the packing metadata
in Sec. 4.7 . The full-attention implementation
supports block-mask execution, caches derived block-sparse metadata, and
provides a native grouped-query path that avoids explicitly repeating
key/value heads. Backend selection depends on the head configuration,
requested execution path, and installed kernels. The linear-attention MoT
implementation provides optimized execution paths alongside a scalar
reference implementation. Expert-specific projections and convolution
weights operate with shared public recurrent state and convolution
history. Private target blocks read this context but do not retain their
local updates in public context. Optimizing these operations must preserve both sample
isolation and the public/private state rules; full-attention visibility and
linear-attention recurrence are not interchangeable. Data delivery and visual encoding. The input pipeline prefetches samples and assembles packed batches.
A frozen VAE encodes visual targets and conditions before the backbone
forward pass, reducing the memory required for visual encoding. Workload-aware monitoring. The implementation supports text and visual loss monitoring by task group,
records token throughput, and estimates utilization with an architecture-aware
FLOP model that distinguishes full-attention and linear-attention layers
and accounts for visual computation. Executed-compute estimates also
consider activation recomputation. Token throughput, peak memory, and
packed sequence lengths provide complementary workload measurements. 6 Experiments We evaluate UniSpark on multimodal understanding, text-to-image

built on a Hybrid MoT Architecture . Specialized understanding and
generation experts share multimodal context through full-attention and
recurrent linear-attention layers. This architecture combines explicit
visual interactions with compact recurrent context in the same backbone.
Joint language modeling and visual flow matching connect image
understanding, generation, and instruction-based editing, while clean
visual context links successive outputs in interleaved sequences.
Diverse multimodal supervision and progressive resolution training extend
this framework to a broad range of tasks and image resolutions up to 2K.
Experiments demonstrate strong multimodal understanding, and visual examples
illustrate generation, editing, and interleaved prediction within the unified
framework.
Our results provide empirical evidence that hybrid attention can
support both multimodal understanding and visual generation within a
unified model. The context-handling design, training recipe, and evaluation
results offer a practical reference for further studies of hybrid
architectures for unified multimodal modeling. References Bai et al. (2026) Qingyan Bai, Qiuyu Wang, Hao Ouyang, Yue Yu, Hanlin Wang, Wen Wang, Ka Leong
