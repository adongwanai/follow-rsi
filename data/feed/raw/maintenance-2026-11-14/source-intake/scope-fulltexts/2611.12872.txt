 Wenya Wang Affiliation: Nanyang Technological University Affiliation: Aumovio Singapore Pte. Ltd. Abstract As multimodal agents accumulate increasingly long interaction histories, effectively retrieving and utilizing past information becomes critical for long-term interaction.
Existing memory systems typically rely on semantic retrieval over compressed memories and expose predefined representations, which may miss relevant memories and overlook heterogeneous evidence needs across queries.
We introduce HiVe-Mem , a multimodal memory framework that interleaves H or i zontal Memory Expansion with Ve rtical Evidence Composition.
For horizontal memory expansion, HiVe-Mem organizes memory episodes into a relational graph using textual and visual anchors, expanding semantically retrieved seeds with related neighbors to recover complementary information.
For vertical evidence composition, each retrieved memory retains multiple evidence forms, including compact summaries, captions, grounded visual views, raw images, and interaction history.
A lightweight trainable selector independently composes an evidence subset for each retrieved memory, enabling query-adaptive utilization of heterogeneous multimodal information.
This two-dimensional design jointly broadens memory coverage and adapts the evidence contributed by individual memories.
Experiments across three multimodal memory benchmarks show that HiVe-Mem consistently improves task performance across base models while reducing token consumption by about 90% compared with the most efficient competing multimodal baselines.
Code is available at https://github.com/ViktorAxelsen/HiVe-Mem 1 Introduction As multimodal agents increasingly engage in persistent interactions involving both language and visual observations, memory becomes essential for preserving and reusing information from past interactions over long horizons ( Hu et al., 2025 ; Huang et al., 2026 ) .
Existing memory systems typically transform interaction histories into compact representations and retrieve relevant entries when needed, allowing agents to access past information beyond the immediate context ( Kang et al., 2025 ; Xu et al., 2025 ; Fang et al., 2025 ; Sun et al., 2023 ) .
In multimodal settings, however, useful information can span multiple modalities and levels of granularity ( Bei et al., 2026 ; Liu et al., 2026a ) , making it difficult for a fixed memory representation and retrieval process to consistently surface the information most useful for future queries ( Liu et al., 2026b ; Wang and Chen, 2025 ; Long et al., 2026 ) .
This raises a fundamental challenge: how can multimodal memory systems flexibly identify and utilize relevant information from heterogeneous interaction histories at inference time? Despite recent progress, existing multimodal memory systems still face two key limitations. First, structured memory is often centered on abstract entities and relations rather than interaction episodes themselves .
While such structures are effective for consolidating knowledge, they may fail to capture cross-episode contextual affinities in multimodal histories, where related episodes can share partial cues across text and images, such as entities, scenes, or events, without forming explicit symbolic relations ( Liu et al., 2025 ; Liu et al., 2026b ) .
As a result, retrieval may still miss relevant episodes beyond directly matched memories, especially when useful information is distributed across multiple interactions. Second, retrieved memories are typically exposed through predefined representations , despite their heterogeneous evidence requirements.
While compact textual abstractions may suffice for some memories, others require fine-grained visual or contextual evidence, making a fixed multimodal representation either insufficient or unnecessarily detailed, thereby limiting memory utilization and increasing token consumption ( Long et al., 2026 ; Wang and Chen, 2025 ) .
These limitations call for a memory framework that can both recover relevant information distributed throughout multimodal histories and adaptively compose the evidence exposed by each retrieved memory. To address these challenges, we propose HiVe-Mem , which broadens semantic retrieval through Horizontal Memory Expansion and tailors the multimodal representation of each retrieved memory through Vertical Evidence Composition .
Horizontally, HiVe-Mem organizes memory episodes into a lightweight relational graph using textual and visual anchors extracted from multimodal histories.
Starting from semantically retrieved seeds, it expands retrieval toward associated episodes through cross-episode contextual affinities, complementing direct semantic matching with relational signals.
Vertically, HiVe-Mem retains multiple evidence forms for each memory, including compact summaries, captions, grounded visual views, raw images, and interaction history.
A lightweight RL-trained selector independently composes the evidence for each retrieved memory conditioned on the query, allowing different memories to expose different evidence subsets while jointly considering answer quality and token consumption.
Together, these two dimensions broaden relevant recall while adapting multimodal evidence to the needs of individual memories.
Experiments across three multimodal memory benchmarks and two base models show consistent improvements over existing multimodal methods with substantially lower token consumption.
Further analyses validate the complementary benefits of horizontal expansion and adaptive evidence composition, demonstrate flexible behavior across query and budget settings, and show only marginal runtime overhead. Our main contributions are summarized as follows: • We propose HiVe-Mem , a multimodal memory framework that jointly improves memory retrieval and evidence utilization, enabling flexible use of long text–image interaction histories beyond fixed retrieval and representation pipelines. • We realize this framework via complementary mechanisms. Horizontal Memory Expansion augments semantic retrieval with cross-episode contextual affinities, while Vertical Evidence Composition adaptively composes multimodal evidence per retrieved memory. • Extensive experiments across three multimodal memory benchmarks and two base models demonstrate improvements over multimodal methods with substantially lower token consumption. Further analyses validate both components and flexible evidence adaptation. 2 Related Work 2.1 Text-Centric Agent Memory LLM agents increasingly rely on external memory to preserve and reuse information beyond bounded context windows ( Zhong et al., 2024 ; Packer et al., 2023 ) . A major line of work transforms interaction histories into compact and reusable representations through extraction, compression, and consolidation ( Chhikara et al., 2025 ; Xu et al., 2025 ; Kang et al., 2025 ; Fang et al., 2025 ; Liu et al., 2026c ) . Beyond independent memory entries, structured approaches organize past experiences through entities, relations, or associative links, allowing retrieval to exploit dependencies among memories rather than relying solely on isolated similarity matching ( Zhu et al., 2026a ) . Another line introduces learned memory management, where policies or evolving operations adapt how memories are constructed, updated, and reused from downstream feedback ( Yan et al., 2025 ; Zhang et al., 2026a ; Yu et al., 2026 ; Wang et al., 2025 ; Zhang et al., 2026b ) . Together, these methods have substantially advanced long-term memory for text-based agents, but remain primarily designed around textual information, leaving heterogeneous multimodal evidence less explored. 2.2 Multimodal Agent Memory Recent work extends agent memory beyond text to persistent visual and multimodal interaction histories. MIRIX ( Wang and Chen, 2025 ) maintains specialized memory types for heterogeneous user information, while M3-Agent ( Long et al., 2026 ) organizes episodic and semantic experience around entity-centric multimodal representations. M2A ( Feng et al., 2026 ) complements raw interaction records with higher-level semantic memories, whereas MemVerse ( Liu et al., 2025 ) consolidates multimodal experience into hierarchical knowledge structures. Recent systems further explore contextual memory organization, reliability-aware retrieval, and unified multimodal memory pipelines ( Jain et al., 2025 ; Lu et al., 2026 ; Liu et al., 2026b ) . Collectively, these methods establish effective mechanisms for storing, structuring, and accessing multimodal experience. In contrast, HiVe-Mem focuses on improving how constructed memories are utilized at inference time, by broadening retrieval through relations among memory episodes and adaptively composing the evidence exposed by each retrieved memory, enabling more effective multimodal memory use. 3 Methodology Our methodology consists of three stages as shown in Figure 1 .
We first organize the interaction history into episode-centric memory representations with complementary textual and visual information in Sec. 3.1 .
We then introduce Horizontal Memory Expansion in Sec. 3.2 to complement semantic retrieval with cross-episode contextual associations.
Finally, Sec. 3.3 presents Vertical Evidence Composition , which adaptively determines the evidence exposed by each retrieved memory. 3.1 Episode-Centric Multimodal Memory Formation We consider a growing interaction history ℋ = { x t } t = 1 T \mathcal{H}=\{x_{t}\}_{t=1}^{T} , where each interaction may contain textual content and associated images.
Rather than treating every turn independently, we partition the history into contiguous interaction episodes (formed over fixed-length token spans), offering a practical granularity while preserving local context.
Each episode e i e_{i} is subsequently transformed into a memory episode m i m_{i} , which serves as the basic memory object in HiVe-Mem . To instantiate each memory episode, we derive a compact summary s i s_{i} with vision-language models (VLMs), providing a concise semantic representation for subsequent retrieval.
To preserve salient information beyond this coarse abstraction, we associate each episode with two sets of fine-grained, VLM-generated modality-aware anchors that capture complementary cues from language and vision.
Specifically, the textual anchors 𝒯 i \mathcal{T}_{i} capture salient semantics from the interaction text, such as entities, events, and topics, while the visual anchors 𝒱 i \mathcal{V}_{i} record visually grounded cues, such as objects, scenes, activities, and attributes, from the associated images.
Visual anchors are useful for retaining visually salient information that may be only partially captured by textual abstractions.
Together, the two anchor sets provide lightweight modality-specific metadata beyond the summary and are used to characterize contextual affinities between memory episodes in Sec. 3.2 . Beyond these compact descriptors, each memory episode retains multiple evidence forms at different levels of detail.
By default, these include the raw interaction text r i r_{i} , compact summary s i s_{i} , image captions c i c_{i} , raw images o i o_{i} , and a grounded visual view g i g_{i} , which we introduce to localize context-relevant regions in the original images while suppressing irrelevant and noisy background, inspired by ( Liu et al., 2026d ) .
Accordingly, each memory episode is represented as m i = ( r i , s i , c i , o i , g i , 𝒯 i , 𝒱 i ) . m_{i}=\big(r_{i},\,s_{i},\,c_{i},\,o_{i},\,g_{i},\,\mathcal{T}_{i},\,\mathcal{V}_{i}\big). (1) This episode-centric representation retains complementary views of multimodal interaction history rather than reducing each memory to a single abstraction.
The compact summary supports semantic retrieval, the modality-aware anchors provide cues for modeling cross-episode affinities, and the evidence forms preserve complementary textual and visual details.

In multimodal histories, relevant context may also be connected through weaker cues distributed across text and images, while explicit entity–relation structures primarily capture symbolic relations. To complement these signals, we model cross-episode contextual affinities between memory episodes. A graph provides a natural substrate for preserving such soft associations without requiring predefined relation types, allowing retrieved memories to serve as entry points for discovering additional relevant context. A single evidence form is unlikely to suit all memories in multimodal settings.
Compact summaries and captions are efficient but may omit fine-grained details, while raw interaction text and images preserve richer information at higher inference cost.
Moreover, the appropriate evidence can vary across both queries and retrieved memories.
We therefore formulate memory utilization as per-memory evidence composition , where each retrieved memory contributes a query-dependent subset of its available evidence. Query-Adaptive Evidence Composition. Together, both dimensions of HiVe-Mem operate complementarily. Horizontal Memory Expansion determines which memory episodes to recall, while Vertical Evidence Composition determines what information each retrieved memory contributes.
Their combination enables query-adaptive use of multimodal interaction history in both memory coverage and evidence granularity. 4 Experiments 4.1 Experimental Settings Benchmarks and Metrics. We evaluate HiVe-Mem on three multimodal memory benchmarks: Mem-Gallery ( Bei et al., 2026 ) , WorldMemArena ( Liu et al., 2026a ) , and H2HMem ( Zhu et al., 2026b ) , covering long-horizon interaction histories with both textual and visual information.
For task performance, we report token-level F1 and an LLM-as-a-judge score (LJ), where GPT-4o-mini is used as the evaluator.
To measure inference efficiency, we additionally report total token consumption (Tok.), summing input and output tokens.
Further details on evaluation protocols and judge prompts are provided in Appendix A.3 . Baselines. We compare HiVe-Mem against two groups of representative memory methods.
For (1) text-centric memory , we include LightMem ( Fang et al., 2025 ) , SimpleMem ( Liu et al., 2026c ) , and BudgetMem ( Zhang et al., 2026b ) , which cover lightweight memory construction, compression, runtime adaptation, and learned memory management.
For (2) multimodal memory , we compare against M2A ( Feng et al., 2026 ) , MIRIX ( Wang and Chen, 2025 ) , MMA ( Lu et al., 2026 ) , and MemVerse ( Liu et al., 2025 ) , which explicitly model and retrieve information from multimodal interaction histories. Implementation Details. We initialize the evidence selector as a lightweight multi-layer perceptron (MLP) and use Proximal Policy Optimization (PPO) as the default reinforcement learning algorithm.
Experiments use Qwen3-VL-4B-Instruct and GPT-5-mini as base models, with GPT-5-mini used only for transfer evaluation (i.e., the selector is only trained on Qwen3-VL-4B-Instruct).
Interaction histories are segmented into episodes of 256 tokens, and Qwen3-VL-Embedding-2B is used for semantic retrieval.
By default, HiVe-Mem retrieves K ret = 5 K_{\mathrm{ret}}=5 seed memories, expands K exp = 2 K_{\mathrm{exp}}=2 additional memories, and sets the maximum graph degree to K edge = 4 K_{\mathrm{edge}}=4 , while all baselines use a consistent Top-7 retrieval setting.
Unless otherwise specified, we set λ = 0 \lambda=0 and further analyze the effect of budget constraints in Section 4.3 .
We split each benchmark into training, validation, and test sets with a 6 : 2 : 2 6{:}2{:}2 ratio.

As shown in Table 1 , text-centric methods generally trail multimodal baselines, highlighting the value of preserving visual information, whereas existing multimodal methods benefit from richer context but often rely on less selective memory utilization. Against this backdrop, HiVe-Mem achieves the best average F1/LJ scores of 32.32/57.96 and 35.94/64.69 with Qwen3-VL-4B-Instruct and GPT-5-mini, respectively, establishing consistent gains over multimodal baselines. The advantage is not driven by a particular benchmark, as HiVe-Mem obtains the best LJ across all three benchmarks with the former backbone and the best F1/LJ across all three with the latter. This improvement supports the benefit of jointly broadening relevant recall and adapting per-memory evidence rather than relying on fixed retrieval and representation schemes. Notably, the latter results use the selector transferred directly from the former without retraining, further indicating cross-model generalization. HiVe-Mem achieves these gains with substantially lower multimodal token consumption. Its average consumption is only 0.658M and 0.748M tokens under the two base models, compared with 7.812M and 7.350M for the most efficient competing multimodal baselines, corresponding to reductions of 91.6% and 89.8%. This efficiency gap partly arises because existing multimodal methods, despite organizing richer memories through multiple stores, hierarchical structures, or reliability-aware retrieval, still expose substantial retrieved context during answering. In contrast, HiVe-Mem composes evidence separately for each retrieved memory, retaining fine-grained textual or visual information only when useful. This enables substantially lower token consumption without sacrificing performance. For completeness, we also include text-centric methods, whose token usage reflects a different modality setting that omits image processing during memory-bank construction.exclude image processing during memory-bank construction. Overall, the results show that HiVe-Mem improves multimodal memory performance while reducing inference context. Its consistent gains across benchmarks and backbones further support the benefits of jointly expanding memory coverage and adapting evidence composition. 4.3 How Does HiVe-Mem Adapt Evidence Composition? To understand how the learned selector adapts under different budget constraints, we vary λ \lambda and analyze evidence usage with Qwen3-VL-4B-Instruct, averaging results across the three benchmarks.
Figure 2 shows a clear shift toward more selective compositions as λ \lambda increases.
The selection rate of raw history drops substantially, while several auxiliary evidence forms are progressively filtered out, indicating that the policy does not reduce cost uniformly across evidence types.
Interestingly, raw images are selected relatively infrequently but contribute an increasingly large fraction of consumed tokens, reflecting their high per-selection cost and the tendency to retain them only when their visual detail is valuable.
This contrast between selection frequency and token share highlights the importance of optimizing evidence utility jointly with consumption. Figure 2 (c) further shows that varying λ \lambda produces distinct quality–token-consumption operating points, allowing HiVe-Mem to explicitly control how aggressively evidence is selected under different budget constraints. As λ \lambda increases, the selector shifts toward more compact evidence compositions and lower token consumption, while smaller values retain richer evidence to prioritize answer quality. Overall, this budget-aware composition enables HiVe-Mem to flexibly adapt to different token budgets without changing the underlying memory system. For Horizontal Memory Expansion, w/o Horizontal Expansion replaces graph expansion with semantic retrieval while keeping the same number of retrieved memories, w/o Visual Anchors removes visual anchors from graph construction, and w/o IDF Weighting assigns shared anchors without IDF-based weighting.
For Vertical Evidence Composition, w/o Vertical Composition represents every retrieved memory using only its compact summary, while the remaining variants individually remove one evidence form from the composition space. Both horizontal expansion and its relational signals contribute to retrieval quality. Disabling Horizontal Memory Expansion reduces LJ from 57.96 to 56.51, showing that retrieving additional memories through cross-episode affinities provides information beyond an equally sized semantic retrieval set.
Removing visual anchors also degrades performance to 57.30, supporting the value of visual cues for connecting multimodal episodes.
Notably, removing IDF weighting causes a larger drop to 56.55, indicating that distinguishing informative anchors from frequently occurring ones is important for constructing useful episode relations. Adaptive evidence composition is particularly important for multimodal memory utilization. Replacing Vertical Evidence Composition with compact summaries alone causes the largest degradation, from 57.96 to 44.47, showing that summary-only representations are insufficient for many queries.
Among individual evidence forms, removing raw text and raw images leads to the largest drops, reaching 49.68 and 51.02 LJ, respectively, highlighting the importance of preserving fine-grained information from both modalities.
Compact summaries, captions, and grounded visual views also provide consistent gains when retained.

We evaluate time to first token (TTFT) on Mem-Gallery to examine the online overhead introduced by different memory systems.
As shown in Fig. 3 (a), several multimodal baselines incur substantially higher TTFT because answering involves additional runtime memory operations, such as agent coordination, memory decomposition, or evidence processing before generation.
In contrast, HiVe-Mem introduces only lightweight graph expansion and evidence composition, resulting in a TTFT of 1.03 seconds.
Although slightly higher than the simplest retrieval-based baselines, this overhead remains marginal and is substantially lower than other multimodal systems in practice.

Appendix Contents Appendix Appendix A Implementation Details A.1 Memory Episode Episode Construction. We construct memory episodes over approximately fixed-length token spans while respecting natural conversational boundaries. In particular, an episode is not forcibly truncated in the middle of a dialogue or session. If the nominal token boundary falls within an ongoing interaction segment, we extend the episode to the nearest valid boundary. This provides a consistent memory granularity while preserving local conversational continuity. Each raw episode is processed only once by a vision-language model (VLM), which jointly produces its compact summary together with the textual and visual anchors introduced in Sec. 3.1 . Grounded Visual View. To obtain a more focused visual representation, we construct the grounded visual view directly from the raw image and its associated interaction context. Specifically, the raw image and the relevant contextual passage are provided to a VLM, which identifies the target object discussed in context and predicts its spatial coordinates. We then crop the corresponding region from the original image to form the grounded visual view. Compared with the raw image, this localized view removes irrelevant background and concentrates visual content around the context-relevant object, yielding a more semantically focused representation. This design also reduces the visual input required by downstream models. Depending on the benchmark, grounded visual views reduce token consumption by approximately 20–40% compared with the raw images. Finally, the evidence forms adopted in this work are not intended to define a fixed evidence space. HiVe-Mem treats evidence composition generically and can accommodate additional textual, visual, or derived representations. The raw interaction, compact summary, caption, raw image, and grounded visual view used here serve as representative evidence forms in our default instantiation. Appendix C Limitations and Future Work Although HiVe-Mem demonstrates consistent effectiveness across multimodal memory benchmarks, several extensions remain open.
First, our experiments instantiate evidence composition with a representative set of textual and visual forms. Future work could incorporate richer derived evidence, such as structured visual descriptions or task-specific representations, within the same framework.
Second, we adopt a lightweight MLP as the evidence selector for efficiency. Exploring alternative selector architectures may further improve evidence composition under different model and task settings.
Finally, our evaluation considers two representative base models. Extending the study to a broader range of model families and scales would provide a more comprehensive understanding of the transferability of HiVe-Mem . Appendix D Broader Impact As multimodal agents evolve from short-lived question answering systems toward persistent interactive systems, the ability to selectively reuse long-term interaction history may become increasingly important. HiVe-Mem provides a step toward memory systems that do not treat stored multimodal information as a fixed representation, but instead adapt both what should be recalled and how retrieved information should be exposed for downstream reasoning. This perspective could support a broad range of long-horizon applications, including personalized assistants, multimodal copilots, embodied agents, and interactive systems that continuously accumulate textual and visual context over time. More broadly, adaptive memory utilization may become a fundamental capability for scalable agent systems. As interaction histories grow, processing all stored information uniformly becomes increasingly impractical. Mechanisms that dynamically recover relevant memories and compose only the necessary evidence could enable agents to maintain richer histories while controlling inference overhead. We hope HiVe-Mem encourages future research toward more flexible multimodal memory architectures that integrate additional modalities, richer memory representations, and increasingly adaptive mechanisms for organizing and reusing long-term interaction history.
