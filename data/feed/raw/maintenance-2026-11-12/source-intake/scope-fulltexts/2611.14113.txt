Abstract Understanding the progress of an activity requires tracking how the objects involved change over time.
Object state readout provides this information by describing a target object’s states and transitions across video frames.
Although multimodal large language models (MLLMs) generate detailed visual descriptions, these descriptions may leave the attributes needed to distinguish successive states insufficiently specified.
In this paper, we propose look-ahead state readout (LASER), an anticipation-guided agent for object state readout that uses possible next-step changes to determine which attributes to inspect in the present.
Given temporally ordered frames and a target object, LASER converts anticipated changes into targeted visual questions and inspects the current frame to establish attribute values.
It then checks state readouts and forecasts against independent observations of subsequent frames, refining a state record used to generate the final description.
Reusable textual observation skills guide this process and are refined by tracing discrepancies with reference captions to the responsible instructions.
Candidate revisions are selected on separate videos based on improved caption quality without increased contradictions with reference facts.
Model parameters remain frozen throughout adaptation and inference, and the revised skills remain fixed during evaluation.
Experiment results and further analysis on OSCaR and PLM RCap show consistent improvements of LASER over strong baselines and existing approaches, which demonstrates the effectiveness of our approach. 1 1 1 Code is available at https://github.com/synlp/LASER . 1 Introduction Object state readout describes how a specified object’s condition changes across visual observations, providing a language account of its evolving state ( Nguyen et al., 2024 ; Cho et al., 2025 ) .
Whereas image captioning describes the content of a single image, state readout tracks object attributes across time to distinguish successive states and their transitions.
This makes state readout an important task for procedural planning and robotic interaction, where understanding how actions change objects supports subsequent decisions ( Nguyen et al., 2024 ) .
The central challenge is deciding which attributes reveal a meaningful change, rather than merely recognizing the object or naming its activity. Multimodal large language models (MLLMs) provide a foundation for describing visual observations in natural language.
Recent studies improve their video descriptions through detailed spatial and temporal grounding ( Xue et al., 2025 ; Cho et al., 2025 ; Kazakos et al., 2025 ; Athar et al., 2025 ) , while temporal benchmarks evaluate their understanding of motion and event order ( Liu et al., 2024 ; Cai et al., 2024 ) .
Related agent studies explore anticipation-guided observation ( Yang et al., 2026 ) and feedback-driven refinement of reusable instructions ( Zhao et al., 2024 ; Zhang et al., 2026 ) .
These capabilities support object state readout, but accurate grounding and temporal ordering alone do not specify which attributes a state description needs to retain for subsequent comparison.
A description may correctly identify an object and its surrounding activity while leaving the property that changes insufficiently specified, weakening the basis for describing its transition across images.
Selecting these attributes requires considering which properties distinguish the object’s possible subsequent states.
For example, for a drawer, opening, closing, and remaining unchanged make its current extension relevant, even when that detail receives little emphasis in a general scene description.
Anticipated changes thus provide a basis for deciding what to inspect, while visual evidence establishes the current attribute value.
The next image provides further evidence for assessing those changes and identifying attributes that require closer inspection.
This connection between possible changes and observable properties motivates using anticipation for attribute selection, subsequent evidence to refine state descriptions, and feedback on those descriptions to improve reusable observation instructions. In this paper, we propose look-ahead state readout (LASER), an anticipation-guided agent that guides an MLLM to inspect an object’s current state by anticipating possible next-step changes.
Given a sequence of video frames and a target object, LASER uses observation skills, expressed as reusable textual instructions, to anticipate alternative changes and identify the attributes that distinguish them.
Predictive attribute selection turns these attributes into visual questions and examines the current image to establish their values.
Sequential visual correction then checks the resulting descriptions and anticipated changes against subsequent images, maintaining an evidence-supported state record for the final description.
To improve the observation skills, feedback-guided skill revision traces discrepancies between generated and reference captions to the instructions responsible for observation and description.
It proposes focused edits and retains those that improve caption quality on separate source videos without increasing contradictions with the references.
This process adapts observation instructions while keeping all model parameters fixed, and the resulting skills remain fixed during evaluation.
We evaluate LASER on English benchmarks across various MLLMs, where our approach outperforms strong baselines and existing studies, demonstrating the effectiveness of our approach. 2 The Approach We propose look-ahead state readout (LASER), an anticipation-guided agent that considers possible next-step changes to guide observation of an object’s current state.
Figure 1 presents its overall architecture, comprising four components: observation skills , predictive attribute selection , sequential visual correction , and feedback-guided skill revision .
LASER organizes observation and reasoning operations and maintains the state record and local guidance; a frozen MLLM executes the visual inspection and language reasoning within these operations.
Specifically, given T T temporally ordered video frames V = ( I 1 , … , I T ) V=(I_{1},\ldots,I_{T}) , a target prompt P P identifying the object, and a task instruction 𝒯 \mathcal{T} specifying the description scope, LASER processes the observations in sequence.
For each observation I t I_{t} , with t = 1 , … , T t=1,\ldots,T , LASER retrieves observation skills from the skill library ℳ \mathcal{M} to guide which attributes of the target object to inspect and how to describe them. Predictive attribute selection uses these skills to propose possible next-step changes, converts their distinguishing attributes into visual questions, and checks the current image to establish the attribute values.
When the next observation arrives, sequential visual correction checks earlier descriptions and anticipated changes against the new evidence. It updates a state record L t L_{t} of observed attributes, changes, and supporting evidence, and local guidance G t G_{t} containing unresolved questions for subsequent inspection.
After the final observation, LASER composes the description Y ^ \widehat{Y} from the final state record L = L T L=L_{T} .
During adaptation, feedback-guided skill revision uses discrepancies in these readout sequences and reference captions to propose instruction edits, then selects edits through replay on separate videos. The observation cycle in Figure 1 follows readout at I t I_{t} through correction when I t + 1 I_{t+1} arrives. The feedback path returns corrected history and local guidance to skill selection and current-attribute inspection for that next observation.
LASER returns the description Y ^ \widehat{Y} and its supporting state record L L : ( Y ^ , L ) = LASER ⁡ ( V , P , 𝒯 , ℳ ) (\widehat{Y},L)=\operatorname{LASER}(V,P,\mathcal{T};\mathcal{M}) (1) The following subsections describe observation skills, predictive attribute selection, sequential visual correction, and feedback-guided skill revision, respectively. 2.1 Observation Skills An observation skill is a structured textual instruction that tells the agent what to inspect about an object and how to describe the visual evidence.
Each skill contains six fields: a trigger specifying when the instruction applies, an attribute scope identifying what to inspect, alternative changes suggesting possible next states, visual signs distinguishing those alternatives, observation operations specifying how to check the current image, and expression constraints governing the resulting description.
We organize these observation instructions into a skill library ℳ \mathcal{M} .
For each observation, the MLLM selects relevant skills to guide inspection (see Section 2.2 for details).
Feedback-guided skill revision updates these instructions using caption feedback (Section 2.4 ). 2.2 Predictive Attribute Selection Predictive attribute selection uses possible next-step changes to determine which attributes matter for describing the object’s current state.
For each image I t I_{t} , the MLLM first observes the target using the task instruction 𝒯 \mathcal{T} and the target information available up to that observation, denoted by P ≤ t P_{\leq t} .
It produces an observation description O t O_{t} containing visible attributes and their values, supporting image regions, and any uncertainty.
This initial observation receives no predicted changes, so its description is grounded in the image.
For t > 1 t>1 , LASER checks earlier descriptions against the new observation before selecting skills.
The resulting K t K_{t} contains the earlier states and observed changes after evidence-supported corrections, while local guidance G t G_{t} records questions that still require inspection.
Both are empty for the first observation.
The MLLM selects skills whose triggers and attribute scopes match O t O_{t} , 𝒯 \mathcal{T} , K t K_{t} , and G t G_{t} , forming ℳ t \mathcal{M}_{t} .
When no skill matches, the MLLM follows the task instruction and directly inspects observable attributes of the target object. Using the selected skills, the MLLM anticipates how the target might change by the next observation.
For t < T t<T , it generates a set of hypotheses H t H_{t} from the current description and the information accumulated so far: H t = Anticipate ⁡ ( O t , K t , G t , ℳ t , 𝒯 ) H_{t}=\operatorname{Anticipate}(O_{t},K_{t},G_{t},\mathcal{M}_{t},\mathcal{T}) (2) Each hypothesis identifies an object attribute, a possible next value or change direction, and a visual sign that would distinguish that outcome.
For a drawer, alternatives might be opening further, closing, or remaining unchanged; they make its current extension an informative attribute to inspect.
These hypotheses concern the next available observation and use only the images observed so far. The MLLM converts the hypotheses into an inspection plan J t J_{t} : a set of questions about the target’s current attributes.
Each question specifies what visual evidence to examine and how that evidence supports a description.
Questions remain neutral about the expected answer; for example, the drawer hypothesis leads to asking how far the drawer is currently extended.
The plan also includes task-relevant attributes already identified in O t O_{t} and unresolved questions in G t G_{t} .
We denote the hypotheses available to planning by H t use H_{t}^{\mathrm{use}} : these are H t H_{t} for t < T t<T and the preceding hypotheses H T − 1 H_{T-1} for the final observation.
The plan is constructed as: J t = Plan ⁡ ( O t , H t use , ℳ t , G t , 𝒯 ) J_{t}=\operatorname{Plan}(O_{t},H_{t}^{\mathrm{use}},\mathcal{M}_{t},G_{t},\mathcal{T}) (3) The MLLM inspects the current image according to J t J_{t} and produces the state readout S t S_{t} by S t = Read ⁡ ( I t , P ≤ t , J t , O t ) S_{t}=\operatorname{Read}(I_{t},P_{\leq t},J_{t},O_{t}) .
The readout records attribute values and their supporting visual evidence, leaving values unresolved when the image is insufficient.
Subsequent observations check this readout and its associated hypotheses through sequential visual correction. 2.3 Sequential Visual Correction When the agent processes image I t I_{t} ( t > 1 t>1 ), sequential visual correction checks the preceding state description S t − 1 S_{t-1} and predicted changes H t − 1 H_{t-1} against the new visual evidence.
The MLLM uses the observation descriptions O t − 1 O_{t-1} and O t O_{t} , which are obtained without predicted values.
If these descriptions provide insufficient evidence, the MLLM examines the two images again to answer the unresolved visual questions.
This additional inspection produces W t W_{t} without receiving the preceding claimed value or predicted outcome; otherwise, W t W_{t} is empty.
The comparison produces feedback E t E_{t} : E t = Compare ⁡ ( S t − 1 , H t − 1 , O t − 1 , O t , W t , 𝒯 ) E_{t}=\operatorname{Compare}(S_{t-1},H_{t-1},O_{t-1},O_{t},W_{t},\mathcal{T}) (4) The feedback identifies supported or contradicted hypotheses, observed state changes, errors in earlier descriptions, and questions that the available evidence does not resolve.
If an object previously observed as standing is now seated, the agent records the transition and rejects a prediction of continued standing; it does not change the earlier standing observation.
An earlier description is corrected only when visual evidence contradicts that description.
When the object’s identity across the two images is uncertain, the agent leaves the transition unresolved. The state record and local guidance start empty: L 0 = ∅ L_{0}=\varnothing and G 0 = ∅ G_{0}=\varnothing .
For t > 1 t>1 , the correction operation applies evidence-supported repairs to the preceding state record L t − 1 L_{t-1} , producing K t K_{t} , while the guidance operation updates the unresolved questions in G t G_{t} : K t = Correct ⁡ ( L t − 1 , E t ) , G t = Guide ⁡ ( G t − 1 , E t ) K_{t}=\operatorname{Correct}(L_{t-1},E_{t}),\quad G_{t}=\operatorname{Guide}(G_{t-1},E_{t}) (5) Here, K t K_{t} contains the corrected history before the current state is added.
Predictive attribute selection then uses K t K_{t} and G t G_{t} to guide inspection of the current image, yielding S t S_{t} .
The agent adds this readout to the corrected history to obtain the updated state record: L t = Update ⁡ ( K t , S t ) L_{t}=\operatorname{Update}(K_{t},S_{t}) (6) For the first image, E 1 E_{1} , K 1 K_{1} , and G 1 G_{1} are empty, and S 1 S_{1} initializes the state record. After all T T images have been processed, the MLLM generates the final description from L T L_{T} .
It selects supported states and changes within the object and temporal scope specified by 𝒯 \mathcal{T} : Y ^ = Compose ⁡ ( L T , 𝒯 ) \widehat{Y}=\operatorname{Compose}(L_{T},\mathcal{T}) (7) 2.4 Feedback-guided Skill Revision Feedback-guided skill revision improves observation instructions using existing reference captions while keeping model parameters fixed.
We divide the source videos into a revision set 𝒟 rev \mathcal{D}_{\mathrm{rev}} for identifying problems and proposing edits, and a selection set 𝒟 sel \mathcal{D}_{\mathrm{sel}} for evaluating those edits.
The sets contain different videos to test whether edits generalize beyond the examples that motivate them.
In each round, LASER processes the revision videos with the current library.
The MLLM compares generated captions with references and examines the corresponding observations, hypotheses, inspection questions, and state records to identify discrepancy sources.
The comparison identifies omissions and explicit contradictions; details unmentioned in the reference remain unjudged. When a relevant attribute is never inspected, it examines whether the skill’s trigger or alternative changes fail to direct attention to that attribute.
When inspection produces an unsupported value, it examines the visual signs and observation operations.
When a supported fact appears in the state record but is missing from the final caption, it examines the expression constraints.
For a discrepancy linked to an existing skill, the MLLM proposes an edit to one responsible field; if no skill covers the situation, it proposes a new skill.
Each proposal produces a candidate library ℳ ′ \mathcal{M}^{\prime} derived independently from the current library ℳ \mathcal{M} .
The MLLM proposes no edit when the available evidence does not identify a responsible instruction. LASER compares each candidate with the current library on 𝒟 sel \mathcal{D}_{\mathrm{sel}} .
For an example x x , which contains the images, target information, and task instruction, let Y x ∗ Y_{x}^{*} denote its reference caption.
The score q q measures agreement between the generated and reference captions, giving the mean caption quality: Q ⁡ ( ℳ ) = 1 | 𝒟 sel | ​ ∑ x ∈ 𝒟 sel q ⁡ ( Caption ⁡ ( x ; ℳ ) , Y x ∗ ) Q(\mathcal{M})=\frac{1}{|\mathcal{D}_{\mathrm{sel}}|}\sum_{x\in\mathcal{D}_{\mathrm{sel}}}q\bigl(\operatorname{Caption}(x;\mathcal{M}),Y_{x}^{*}\bigr) (8) Here, Caption \operatorname{Caption} returns the description produced by Equation 1 ; references are used for scoring rather than caption generation.
To check contradictions, the MLLM extracts explicit facts from each reference caption once and uses the same facts to assess every candidate.
An MLLM judge determines whether a generated caption contains a claim incompatible with a reference fact concerning the same object and temporal scope.
Omissions, details absent from the reference, and uncertain comparisons do not count as contradictions.
The contradiction score X ⁡ ( ℳ ) X(\mathcal{M}) is the fraction of selection examples containing at least one explicit contradiction. Selection requires an improvement in caption quality without increasing reference contradictions.
For a positive quality margin ϵ \epsilon , the acceptance rule is: Accept ( ℳ ′ ) = [ Q ( ℳ ′ ) − Q ( ℳ ) ≥ ϵ , X ( ℳ ′ ) ≤ X ( ℳ ) ] \operatorname{Accept}(\mathcal{M}^{\prime})=\mathbf{1}\!\left[Q(\mathcal{M}^{\prime})-Q(\mathcal{M})\geq\epsilon,\;X(\mathcal{M}^{\prime})\leq X(\mathcal{M})\right] (9) The accepted candidate with the highest caption quality replaces the current library; if none is accepted, the library is retained.
The resulting skill library remains fixed during evaluation. 3 Experiment Setting 3.1 Datasets We evaluate object-conditioned captioning on OSCaR ( Nguyen et al., 2024 ) and PLM RCap ( Cho et al., 2025 ) .
We use OSCaR’s released EPIC state-change slot, containing 7K training clips and 500 test clips.
Each example pairs three ordered frames with a named object and a reference description of its state change.
PLM RCap contains 179K training, 4K development, and 10K test region–interval captions.
Given a target masklet and its video interval, the task describes the target’s actions and interactions.
For each benchmark, we select 500 examples from its training split and use their reference captions to adapt observation skills.
We divide these examples into video-disjoint revision and selection sets, using the former to propose instruction edits and the latter to evaluate them. 3.2 Baselines and Comparing Models We compare LASER with the following baselines. Direct Captioning generates a target description from the input frames and task instruction in one pass. Sequential Readout describes object states in temporal order and summarizes their changes without anticipating future states. Generic Reinspection extends sequential readout by checking for omissions or inconsistencies. Attribute Checklist selects current-state attributes for inspection and retains visual correction, without next-step hypotheses. Free Anticipation predicts possible future events without identifying their distinguishing attributes and visual signs. LASER (No Skill Revision) uses unadapted initial observation skills. LASER (GEPA Optimization) uses GEPA ( Agrawal et al., 2026 ) to optimize the same prompt interfaces instead of feedback-guided skill revision. LASER (Full) is our full approach. We also compare LASER with five existing approaches. InstanceCap ( Fan et al., 2025 ) organizes video instances into structured descriptions of their appearance, actions, motion, and position. Matters ( Peng et al., 2025 ) describes local image patches and hierarchically aggregates their details through semantic filtering. RICO ( Wang et al., 2025a ) reconstructs images from captions and revises the captions by comparing the reconstructions with the original images. ReAgent-V ( Zhou et al., 2025 ) combines task-relevant frame selection and tool-derived evidence with critical feedback and multi-perspective answer revision. ScaleCap ( Xing et al., 2026 ) expands captions through targeted visual questions and filters unsupported sentences through contrastive scoring.
We adapt these approaches to object-conditioned captioning and evaluate them on the benchmarks. The two dense Qwen models each have 32 language layers, with hidden dimensions of 2,560 and 4,096 for the 4B and 9B variants, respectively.
The 35B-A3B variant uses 40 language layers with a hidden dimension of 2,048; its mixture-of-experts layers select 8 of 256 routed experts per token and include a shared expert, with an intermediate dimension of 512 for each expert.
Ministral-3-3B has 26 language layers with a hidden dimension of 3,072 and a 24-layer vision encoder. We divide the adaptation examples into revision and selection sets at a 4:1 ratio, keeping examples from the same video in one set.
For PLM RCap, we uniformly sample eight frames from each target interval; OSCaR uses its three provided frames.
At each observation, LASER selects up to three relevant skills and generates up to three alternative next-step changes.
Skill adaptation runs for at most five rounds, with up to three candidate libraries evaluated per round.
We normalize caption quality scores to [ 0 , 1 ] [0,1] and require an improvement of at least ϵ = 0.005 \epsilon=0.005 without increasing reference contradictions.
Adaptation stops when no candidate satisfies these criteria.
All model parameters remain frozen, and the adapted skill library remains fixed during evaluation. For evaluation, we use different metrics for the two benchmarks.
For OSCaR, we report BLEU ( Papineni et al., 2002 ) , ROUGE-1, ROUGE-2, and ROUGE-L ( Lin, 2004 ) , with ROUGE-L as the primary metric.
For PLM RCap, we use the official language-model-judged reference-caption similarity score ( Cho et al., 2025 ) .
Higher values indicate better caption agreement on both tasks.
Evaluation references are accessible only to the scorer. 4 Results and Analysis 4.1 Overall Results Table 1 presents the results of our approach and baselines on OSCaR and PLM RCap across four backbone MLLMs.
There are several observations.
First, LASER consistently outperforms direct captioning, sequential readout, and generic reinspection across all metrics.
These gains suggest that accurate state descriptions benefit from selecting informative attributes beyond organizing observations temporally or inspecting them repeatedly.
Second, LASER achieves higher scores than both attribute checklists and free anticipation across the evaluated backbones.
This supports connecting possible changes to specific visual attributes, so that anticipation guides what to inspect in the current image.
Third, feedback-guided skill revision improves every reported metric over LASER with the initial skill library.
This indicates that caption feedback helps refine reusable observation instructions without updating model parameters.
Fourth, LASER improves over direct captioning for all four backbones, spanning different model sizes, model families, and dense and mixture-of-experts architectures, which demonstrates the robustness of our approach. Using Qwen3.5-9B as the backbone MLLM on both benchmarks, we independently remove current reinspection, remove discriminating visual signs, or expose the initial observer to preceding hypotheses, retaining the full approach’s revised skills in each case.
Table 3 compares these variants with full LASER and direct captioning.
Removing current reinspection lowers every metric, supporting the use of anticipated changes to guide a second examination of the present image.
Removing discriminating signs also lowers every metric and produces the largest ROUGE-L decline among the ablations.
This pattern suggests that identifying possible changes is more useful when those changes are connected to explicit visual criteria for inspection.
Exposing the initial observer to predicted changes reduces all reported scores and produces the largest decline in RCap similarity among the ablations.
The result supports keeping initial visual observations independent of forecasts, so that later comparisons rely on separately obtained evidence.
All three ablated variants remain above direct captioning, indicating that each removed operation contributes to the full approach while the remaining observation structure retains value. Figure 2 shows the input frames and target regions in panel (a), state estimates and predictions in panel (b), subsequent visual checks in panel (c), and the generated and reference captions in panels (d) and (e).
Green contours identify the target whose state is tracked. In Case 1, the anticipated forward lean directs inspection toward the target’s torso angle relative to the sink.
The later image supports this change, and the final caption describes the lean while preserving the ongoing dishwashing activity.
The reference mentions dishwashing without explicitly describing the lean, so the displayed images provide the evidence for this additional posture detail.
The case illustrates how an anticipated change becomes a specific visual criterion used in the final description.
In Case 2, LASER anticipates continued standing with a slight forward lean, but the later observation shows the target seated on the bicycle.
Sequential visual correction rejects the forecast, retains the earlier standing state, and records the newly observed transition.
The final caption describes the target sitting on the bicycle, consistent with the reference’s account of getting onto it.
The case illustrates that an incorrect forecast still leaves room for evidence-supported state readout: subsequent observations determine the transition without changing a supported earlier state. 5 Related Work Object-centered video understanding studies state localization ( Xue et al., 2024 ; Souček et al., 2022 ) , transformation graphs ( Sun et al., 2025 ) , and segmentation through appearance changes ( Yu et al., 2023 ) .
Region-captioning approaches emphasize object representations ( Yuan et al., 2025 ) and local–global context ( Lian et al., 2025 ) , while OSCaR ( Nguyen et al., 2024 ) and PerceptionLM ( Cho et al., 2025 ) provide state-change and region-captioning tasks, respectively.
Agent approaches organize reasoning and interaction ( Yao et al., 2023 ) , execute visual programs ( Gupta and Kembhavi, 2023 ) , and gather evidence through iterative inspection ( Wang et al., 2024 ) , keyframe selection ( Wang et al., 2025b ) , or evidence-sufficiency assessment ( Wang et al., 2026 ) .
StreamAgent anticipates where and when task-relevant information will appear to guide evidence acquisition and response timing in streaming video question answering ( Yang et al., 2026 ) .
Other uses of possible outcomes include counterfactual supervision for video representation learning ( Kung et al., 2025 ) and robot behavior forecasting in TRACE ( Puthumanaillam et al., 2025 ) .
Feedback-based approaches revise responses ( Madaan et al., 2023 ) or retain experience as reflections ( Shinn et al., 2023 ) , workflows ( Wang et al., 2025c ) , manuals ( Chen et al., 2024 ) , and evolving contextual playbooks ( Zhang et al., 2026 ) .
Prompt optimization uses scored candidates ( Yang et al., 2024 ) , textual critiques ( Pryzant et al., 2023 ) , modular instruction search ( Khattab et al., 2024 ; Opsahl-Ong et al., 2024 ) , and feedback propagation ( Yuksekgonul et al., 2025 ) ; GEPA uses execution traces to reflect on and evolve prompts ( Agrawal et al., 2026 ) .
LASER focuses on the role of anticipation in determining what constitutes an informative description of the present: alternative next-step changes identify the object attributes and visual signs to inspect in the current image, whose evidence establishes their values.
Subsequent observations check these values and transitions, while caption discrepancies guide revisions to the responsible attribute-selection, visual-inspection, or expression instructions, making the observation criteria themselves the target of adaptation. 6 Conclusion In this paper, we propose look-ahead state readout (LASER), an anticipation-guided agent that uses possible next-step changes to determine which object attributes deserve attention in the present.
LASER converts anticipated changes into current-state inspection questions and uses subsequent visual evidence to refine the state record for description.
Feedback-guided skill revision improves reusable observation instructions through caption feedback while keeping all model parameters fixed.
Experiments on OSCaR and PLM RCap demonstrate consistent improvements over direct captioning and alternative observation strategies across four MLLM backbones, and LASER outperforms the five compared existing approaches.
