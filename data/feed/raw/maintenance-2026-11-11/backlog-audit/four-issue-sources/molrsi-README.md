# MolRSI project website

Static research project website prepared for https://yikunpku.github.io/MolRSI/.

This repository contains the project website, figures, videos, and chart data. It does not contain the MolRSI model, agent implementation, or training source code.

## Deployment

Publish the contents of this directory at the root of the `MolRSI` GitHub Pages site. No build step or server backend is required. `.nojekyll` keeps the files available as plain static content. The relative asset paths support the `/MolRSI/` project path.

## Research evidence

The page retains the supplied manuscript's scientific wording and qualifications. Predicted pMHC structures are models; experimental selectivity is relative to the tested off-target panel. The antibacterial cohort hit criterion is MSSA MIC <=32 micrograms/mL; MRSA results refer to separate selected-hit follow-up experiments. The interactive comparison retains the original chart data and missing-data gaps.
