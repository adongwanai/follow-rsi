Salim Affiliation: University of New South Wales Abstract Language-model agents use experience through external retrieval and parameter learning. Consolidating stored experience into model weights requires deciding both which experience to train on and when its external records can leave retrieval. Admission based solely on student mastery can exclude useful teacher demonstrations, while removal immediately after training can discard guidance that the model still needs. We introduce Engram , a framework that separates training admission from memory release. A demonstration-aware gate admits skills based on student mastery or sufficient successful teacher demonstrations. The student learns from selected action traces with context from an Engram Trace Graph (ETG). A verification gate then compares the updated model without episodic retrieval against the base model with retrieval on reserved probes. Release requires valid training participation and scores meeting both relative and absolute criteria; records for skills that fail verification remain retrievable. Experiments across interactive and reasoning benchmarks show consistent gains over frozen-weight ETG controls, with ablations supporting demonstration-aware admission and selective adapter activation. A controlled held-out comparison shows that verified release substantially reduces the retrievable footprint while remaining close to retain-all performance and outperforming immediate and budget-matched random release. Engram also improves task performance while reducing input-token usage and model calls. Skill-level verification further reduces retrievable experience through selective archival, retaining external guidance for skills that do not meet the release criteria. Code is available in anonymous.4open.science/r/engram-anonymous. 1 Introduction Language-model agents use past experience through external retrieval and parameter updates. Retrieval keeps trajectories and feedback available for future tasks, while parameter learning can make their lessons usable without consulting the original records. Combining these mechanisms raises a practical question: when has an agent learned enough from stored experience to remove the corresponding records from its retrieval memory? Retaining every record incurs storage and retrieval costs, but premature removal can discard guidance that the model still needs. Existing methods illustrate both approaches. Reflexion stores verbal feedback, Voyager accumulates executable skills, and MAGE organizes successful and failed experiences in a co-evolving graph ( Shinn et al., 2023 ; Wang et al., 2023 ; Yang et al., 2026 ) . Self-training methods such as STaR and ReST EM instead update model parameters using selected generated solutions ( Zelikman et al., 2022 ; Singh et al., 2023 ) . An agent combining retrieval and training must distinguish useful learning material from records that are no longer needed after learning. First, useful training experience may precede student mastery. A student can fail at prerequisite actions before reaching a more advanced skill. A stronger teacher can demonstrate that skill, but a mastery-only admission rule would still exclude it from training. Admission should therefore consider available demonstrations alongside current competence. Second, completing training does not establish that memory can be removed. A selected skill may contribute no valid training examples, or the updated model may still depend on retrieved guidance. Premature removal creates knowledge waste : external experience becomes unavailable before the weights can replace it. This can happen immediately after consolidation, independently of interference from later updates. Figure 1: Readiness to learn differs from readiness to release. Removing both traces after training can leave skill B unsupported if only A has been learned. Verifying this transfer requires comparing the updated model without episodic retrieval against a retrieval-supported reference under the same task interface. Otherwise, retrieved demonstrations or differences in prompt format can obscure what the weights have learned. Action probes provide local evidence; complete rollouts and subsequent updates assess task performance and retention. We introduce Engram , a framework that separates training admission from memory release for each skill. The Engram Trace Graph (ETG) organizes experience by skill, outcome, and source. A demonstration-aware gate admits skills with sufficient student mastery or successful teacher demonstrations. Periodic consolidation trains a low-rank adapter on valid action traces with ETG context, incorporating replay when enabled. A verification gate compares the candidate without episodic retrieval against the base model with retrieval on reserved probes. Release requires valid training participation and scores meeting both a relative threshold and an absolute floor. Approved skills use verified weights without episodic retrieval; other skills retain external guidance, optionally with a separately approved adapter. Inspired by complementary learning systems ( McClelland et al., 1995 ) , this process connects experience acquisition with parameter learning and selective memory release. Experiments across interactive and reasoning benchmarks show Engram outperforms most of baselines on multiple benchmarks. Ablations support the contributions of demonstration-aware admission and adapter activation, while showing that external guidance remains useful after training. A separate analysis illustrates how skill-level verification reduces retrievable experience through selective archival. Specifically, our contributions are: 1. Demonstration-aware training admission. A per-skill rule admits useful teacher demonstrations independently of current student mastery, expanding the experience available for parameter learning. 2. Verification before memory release. A separate gate requires training participation and behavioral evidence from reserved probes before removing records from retrieval. 3. Performance and efficiency gains. Benchmark evaluations and ablations demonstrate improved task performance, while serving measurements show reduced token usage and model calls in sequential interaction and lower latency in QA relative to Base+ETG. Skill-level analysis additionally demonstrates selective reduction of retrievable experience. 2 Related Work Self-evolution through policy learning. STaR and ReST EM improve model parameters by generating, filtering, and learning from the model’s own solutions ( Zelikman et al., 2022 ; Singh et al., 2023 ) . Other methods train the behaviors that support iterative improvement: RISE learns multi-turn revision after unsuccessful attempts, while SCoRe learns self-correction through online reinforcement learning ( Qu et al., 2024 ; Kumar et al., 2024 ) . SEAL generates self-edits whose supervised updates improve downstream performance ( Zweiger et al., 2025 ) . Agent0 extends policy learning through the co-evolution of a task-generating curriculum agent and a tool-using executor ( Xia et al., 2025 ) . These methods provide mechanisms for improving an agent’s capabilities through parameter updates. Self-evolution through external memory. External experience also supports adaptation without updating the acting model’s weights. Reflexion stores verbal feedback, Voyager accumulates executable skills, and Agent-Pro refines an explicit behavioral policy through reflection and search ( Shinn et al., 2023 ; Wang et al., 2023 ; Zhang et al., 2024 ) . Memento uses case-based memory, while MAGE organizes skills, successful traces, and teacher corrections in a co-evolving graph ( Zhou et al., 2025 ; Yang et al., 2026 ) . Recent work also adapts how memory is managed: MemRL learns retrieval utilities from environmental feedback; MemSkill learns a memory-skill selector and revises memory routines; and EvolveMem adjusts retrieval configurations through failure diagnosis and regression checks ( Zhang et al., 2026b ; Zhang et al., 2026a ; Liu et al., 2026 ) . Memento-Skills develops reusable skills and stateful prompts through a read–write learning loop ( Zhou et al., 2026 ) . M excludes task-local blackboards, archives used only for gradient updates, and fixed factual corpora. Joint evolution of weights and memory. Several methods combine external experience with policy learning. EvolveR couples distilled principles with reinforcement learning, and SkillRL jointly develops a hierarchical skill library and the agent policy ( Wu et al., 2025 ; Xia et al., 2026 ) . AgentEvolver reuses an experience pool during policy learning, while EDGE combines gain-gated distillation with utility-based experience pruning ( Zhai et al., 2025 ; Xie et al., 2026 ) . This combination also relates to complementary learning systems, which distinguish rapid experience storage from gradual integration into distributed representations ( McClelland et al., 1995 ) . Within this setting, Engram focuses on two decisions: when stored experience should enter training, and when its external records can be removed. The teacher acts through the same environment interface, and the observed target outcome determines demonstration success. ETG associates each record with its skill, outcome, and source. These associations determine both which examples enter training and which records a release decision may remove. Appendix A details trajectory construction. ETG records. The full method improves over ETG with frozen weights by 3.1–8.4 percentage points across all six benchmarks. SFT without inference-time ETG also exceeds this baseline throughout, indicating that training provides benefits beyond retrieved guidance. This supports admitting successful teacher demonstrations before the student reliably performs the associated skill. Activation and external guidance. Removing the activation gate lowers scores on every benchmark. Disabling inference-time ETG after SFT produces larger decreases, particularly on ALFWorld and WebShop. A strong teacher executes action sequences through the same environment interface. The environment’s reported target outcome determines demonstration success. For achievement-based environments, the stored segment ends at the action that unlocks the achievement, and a target-directed episode can stop once that event occurs. This alignment retains the action that caused success rather than an arbitrary prefix of the rollout. Teacher demonstrations complement student successes and teacher-written failure corrections. A correction enters action training only if it supplies a valid action for an aligned observation. Source tags distinguish demonstrations, corrections, and student traces. development data used for controller verification, and
held-out data used for final evaluation. The intended unit
of separation is the originating episode: segments from the
same episode should remain in one partition even when they
are associated with different skills. For QA, normalized
questions are deduplicated across partitions before answers
are attached. Question–answer matching provides an additional
check rather than replacing question-level separation.
The final evaluation pool is excluded from gate tuning,
checkpoint selection, and prompt development. Sequential probe construction. In ALFWorld, the consolidator groups identical
observation–action–prompt trajectories across skill labels,
preserves the reserved groups across rounds, and excludes
trajectories already present in replay. Other sequential
environments reserve a deterministic tail of successful
memory records per skill after sorting by node identifier.
Reserved records are excluded from the current consolidation
batch. Observation–action probes include up to 16 recent
history entries and are subject to a probe-step cap. Verification conditions. The candidate arm uses the adapted model without episodic
retrieval; the reference arm uses the base model with ETG.
Both arms use the same task interface and scoring procedure.
The implemented reference arm retrieves from the pre-release
store. Removing a record from the training batch does not
necessarily remove it from this retrieval store, so this
condition is distinct from source-excluded retrieval. For sequential tasks, probes measure agreement with recorded
actions using the same environment prompt builder and action
parser. Agreement is a local behavioral diagnostic: it can
depend on the action classes represented in the probe and
does not capture all valid alternative actions or subsequent
environment states. For the QA release analysis in
Figure 4 , each question is counted
as successful when answer F1 is at least 0.5. The skill-level
score is the fraction of successful development questions.
Release requires this fraction to exceed 50%, together with
the relative-performance and training-evidence checks.
These answer-level scores are distinct from next-action
agreement. Statistical unit. Paired comparisons match methods by environment world or
task instance. Bootstrap draws resample the same instances
for all compared methods and recompute the reported metric.
For Crafter, each sampled world retains its complete
achievement vector; progress or geometric score is then
computed from the resulting achievement rates. Paired differences are summarized with percentile 95%
bootstrap intervals. For evaluations with multiple evolution
seeds, seed-level variation is distinguished from
instance-level uncertainty, with hierarchical resampling
where applicable. Single-checkpoint analyses quantify
variation over evaluation instances rather than variation
across independently trained models. The fraction of
bootstrap draws favoring a method is descriptive and is
not reported as a hypothesis-test p p -value. Interaction and compute accounting. We distinguish student acquisition, teacher acquisition,
verification, consolidation, and final evaluation costs.
Serving measurements include all model calls and tokens
used by each method, including reflection and repeated
generation. Last-attempt success and best-of-attempt success
are different outcomes and are identified separately when
reported. Matched-data controls reuse the same acquired
experience; this does not imply equal end-to-end acquisition
or training cost. Decision and memory accounting. Release decisions are associated with the evaluated
checkpoint and the supporting training and probe evidence.
The relevant quantities include student mastery, available
teacher demonstrations, realized training examples, probe
size, candidate and reference scores, and the configured
relative threshold and absolute floor. Memory accounting distinguishes records available for
retrieval, records moved to a non-retrievable archive, and
separately retained training data. Counts before and after
release are reported for the affected stores. Archival
release reduces retrieval availability without necessarily
reducing total storage. LLM-only control. For QA, LLM-only denotes one greedy zero-shot chain-of-thought
generation from the unadapted student using the question and
the benchmark-supplied context, without episodic retrieval,
additional search, or an adapter. Interactive controls with
handcrafted strategy hints or action substitutions are
identified separately rather than labeled LLM-only. E.1 Controlled evaluation of memory release Shared experimental conditions. We use the fixed Qwen3-8B SFT checkpoint and the initial
store of 600 HotpotQA experience records analyzed in
Figure 4 .
All conditions share the checkpoint, skill assignments,
prompt construction, retrieval settings, and decoding
configuration. No additional parameter updates are
performed during this comparison.
Development probes determine release decisions before
held-out evaluation; test results are not used to revise
these decisions or their thresholds. Release-policy controls. We compare the following policies: • Retain all. All experience records remain retrievable, and all
skills use the fixed adapted model with ETG. • Immediate release. Skills that contributed valid training examples
release their eligible records after training,
without post-training behavioral verification. • Verified release. Eligible records are released only for skills that
satisfy the training-evidence checks, relative
verification threshold, and absolute performance
floor. • Random release. Release selections are sampled without using probe
scores and matched to the verified policy’s
retrievable record count.
We repeat the random selection to measure variation
due to the choice of released memories. For every policy, skills selected for release use the
same adapted model without episodic retrieval.
Other skills use that model with the remaining ETG.
Adapter activation is fixed rather than independently
recomputed for each policy.
Record eligibility, shared-record handling, and any
configured residual retention are applied consistently
across conditions.
Released records are moved to a non-retrievable archive;
the comparison therefore measures retrieval reduction
rather than total-storage reduction. Held-out performance and uncertainty. We evaluate every condition on the same held-out questions
and report aggregate answer EM and token F1.
For each release policy, we compute the paired F1 difference
relative to retaining all records.
Paired bootstrap draws resample test questions using the
same indices for both conditions and recompute the score
difference, yielding percentile 95% confidence intervals. For random release, we report performance averaged over
the sampled release selections and account for both
selection-level and question-level variation through
hierarchical bootstrap resampling.
These intervals quantify uncertainty for the fixed
checkpoint, rather than variation across training seeds. At inference time, the controller assigns the current request or interaction state to a skill using only deployment-visible information and the same skill taxonomy used during ETG construction. The router does not observe gold answers, episode success, future environment states, verification outcomes, or held-out annotations. Given the resulting skill key, the controller loads the most recent approved adapter version for that skill; if no approved version exists, it executes the Base+ETG route. Controller implementation. The consolidator selects skills, constructs training examples and reserved probes, continues the adapter, loads the candidate into the serving engine, and evaluates release eligibility. The environment prompt builder is shared by training and evaluation. Training or loading failure preserves the source records. Skills with no valid training examples or no eligible probe remain external. The sequential gate filters probe states to the corresponding deployment route. whose coverage may not capture every deployment condition.
Our controlled release study evaluates a fixed checkpoint;
extending this analysis to longer sequences of consolidation
and changing task distributions would clarify the durability
of release decisions. Consolidation schedules and verification
thresholds are also configured per benchmark. Adapting these
settings online is a promising direction for broader deployment. Appendix H Essential Prompt Interfaces Training and deployment share the benchmark’s task interface.
