Tsinghua University Abstract Large language model (LLM) agents have demonstrated strong capabilities in complex tasks, including code generation, tool use, and multi-hop question answering. Existing self-improvement methods enhance agent performance through model optimization, harness evolution, and executable artifact refinement, while recursive self-improvement (RSI) further extends optimization to the improvement mechanisms themselves. However, adapting self-improvement workflows to evolving performance bottlenecks while improving workflow orchestration through execution feedback remains a key challenge. We propose RSIFlow , a R ecursive S elf- I mprovement framework that integrates adaptive work flow orchestration with meta-agent capability evolution. RSIFlow diagnoses performance bottlenecks from task-agent trajectories and environmental feedback to dynamically select component-specific improvement workflows. The meta-agent then distills workflow outcomes into component-specific skills and cross-component principles, evolving its own harness to improve subsequent workflow orchestration. Experiments across six benchmarks and two backbone models show that RSIFlow achieves the SOTA average performance on all benchmarks. Ablation studies further demonstrate the contributions of adaptive workflow orchestration and meta-harness evolution. Code is available at https://github.com/1HUAN1/RSI-Flow. (B) The execution loop of RSIFlow. 1 Introduction Recent advances in large language models (LLMs) have enabled agents to tackle complex tasks in coding, tool use, and multi-hop question answering ( Yang et al., 2024 ; Schick et al., 2023 ; Yao et al., 2023 ) . To continuously enhance the development of agents’ capabilities in task domains, existing methods have adopted complementary approaches, including evolving execution harnesses ( Zhang et al., 2025 ) , optimizing model parameters ( Luo et al., 2025 ) , and refining executable artifacts ( Novikov et al., 2025 ) . These routes can be organized into self-improvement workflows that propose and evaluate changes using task feedback. Beyond executing such workflows, recursive self-improvement (RSI) seeks to strengthen not only task-solving capabilities but also the mechanisms that generate subsequent improvements ( Zhang et al., 2026c ; Duan et al., 2026 ) . Research on agent self-improvement spans three increasingly broad scopes of optimization. Component-level approaches optimize a predefined part of the system, such as the model or the harness (execution workflows) ( Luo et al., 2025 ; Zhang et al., 2026b ) . System-level approaches coordinate updates across components, including joint model–harness optimization and feedback-driven selection of update targets ( Chen et al., 2026d ; Chen et al., 2026b ; Hebbar et al., 2026 ) . Meta-level approaches make improvement procedures editable through operator scheduling, program modification, and recursive skill evolution ( Tan et al., 2026 ; Zhang et al., 2026c ; Wang et al., 2026 ) . These developments expand both what can be modified and how modifications are organized. However, broader editability alone does not establish how effectively a workflow addresses the agent’s current bottlenecks, or whether the ability to organize that workflow improves with experience. This motivates a central question: how can RSI systems adapt self-improvement workflows to evolving bottlenecks while learning to organize these workflows more effectively? We formulate this challenge as dynamic workflow adaptation in RSI, where adapting bottlenecks and evolving workflow orchestration must be considered together. As illustrated in Fig. 1 , self-improvement workflows must adapt to bottlenecks that vary with task requirements and the agent’s capability state. Even within a fixed domain, successful updates can reshape these bottlenecks and alter the effectiveness of subsequent workflow orchestration. Meanwhile, workflow orchestration is itself a capability that can improve through experience. Feedback from workflow execution supports the accumulation and refinement of reusable knowledge for diagnosis, workflow selection, and execution. These processes form a feedback loop: task-level updates reshape improvement requirements, while workflow experience refines the orchestration capability that guides subsequent updates. To address this challenge, we propose RSIFlow , a framework that couples adaptive workflow orchestration with meta-agent capability evolution . We instantiate three self-improvement workflows targeting the Harness , Model , and Artifacts . A meta-agent uses execution trajectories and environmental feedback to diagnose the task agent’s bottlenecks, select a workflow, and orchestrate candidate generation and validation. It then distills orchestration outcomes into component-specific skills and cross-component principles to revise its own harness, including execution procedures and skill invocation. This experience-driven self-revision closes a recursive feedback loop in which workflow orchestration outcomes refine the orchestration mechanism that guides subsequent improvements. Our main contributions are: • We formulate dynamic workflow adaptation as a key challenge in RSI, highlighting the coupling between evolving performance bottlenecks and continual refinement of workflow orchestration. • We propose RSIFlow , which adaptively organizes self-improvement workflows and uses their observed outcomes to evolve the meta-agent’s own harness, including its execution procedures and reusable skills. • We evaluate RSIFlow across six benchmarks and two backbones, outperforming the strongest evaluated baseline in 11 of the 12 benchmark–backbone settings. Ablations support the benefits of both adaptive workflow orchestration and meta-harness evolution. 2 Related Work Component-Specific Self-Improvement. Many approaches to agent self-improvement optimize a single predefined component. STaR ( Zelikman et al., 2022 ) improves model parameters by repeatedly fine-tuning on self-generated rationales that yield correct answers. AFlow ( Zhang et al., 2025 ) searches code-represented workflows, while Recursive Harness Self-Improvement ( Lee et al., 2026 ) refines prompt-level harness specifications using pairwise feedback over revision histories. Related approaches include DSPy ( Khattab et al., 2024 ) for language-model pipeline optimization, GEPA ( Agrawal et al., 2026 ) for reflective prompt evolution, and ADAS ( Hu et al., 2025 ) for meta-agent-guided search over agent programs. In contrast, AlphaEvolve ( Novikov et al., 2025 ) evolves candidate programs through execution-based evaluation, targeting task artifacts rather than the agent’s improvement procedure. Self-Refine ( Madaan et al., 2023 ) iteratively revises outputs using self-feedback, while Reflexion ( Shinn et al., 2023 ) retains verbal reflections to guide subsequent attempts and Voyager ( Wang et al., 2024 ) accumulates reusable executable skills. Co-Harness ( Chen et al., 2026d ) and HarnessForge ( Chen et al., 2026b ) connect external structure and internal capability by alternating harness refinement with model optimization. Their coupled updates address model–harness compatibility, but the prescribed update order leaves open how to adapt workflow orchestration targets to evolving bottlenecks. Beyond prescribed alternation, SIA ( Hebbar et al., 2026 ) uses trajectory and performance feedback to choose between harness and weight updates, while its selection policy relies on a frozen language-model prior. HASE ( Luo et al., 2026 ) integrates task solving and harness editing into one action space and trains the policy with GRPO. A complementary direction makes the improver itself editable: Hyperagents ( Zhang et al., 2026c ) co-evolves task-agent and meta-agent programs and demonstrates transferable improvement strategies, whereas MetaSkill-Evolve ( Wang et al., 2026 ) recursively updates task skills and their improvement procedures on different timescales. We train RSIFlow on training data from three task domains and evaluate it on six public benchmarks spanning the same domains: (1) code generation, HumanEval+ and MBPP+ ( Liu et al., 2023 ) . (2) tool use, BFCL-v3 ( Patil et al., 2025 ) and ACEBench ( Chen et al., 2025 ) . (3) search-QA, HotpotQA ( Yang et al., 2018 ) and 2Wiki ( Ho et al., 2020 ) .
Detailed descriptions and evaluation metrics are in App. A.2 Baselines. We compare RSIFlow with three series of baselines: (1) model-only evolution , including SFT ( Ouyang et al., 2022 ) and GRPO ( Shao et al., 2024 ) ; (2) harness-only evolution , including AFlow ( Zhang et al., 2025 ) and MermaidFlow ( Zheng et al., 2025 ) ; (3) model-harness both evolution, including HarnessForge ( Chen et al., 2026b ) and SIA ( Hebbar et al., 2026 ) , Hyperagent ( Zhang et al., 2026c ) further evolves the harness of the meta agent, incorporating the evolution of the meta into the cycle.

The Meta-Agent uses GPT-5.6 Sol as its base model.
We run R = 5 R=5 evolution rounds and report the main results with a maximum of two attempts per evolution round.

RSIFlow leads in 11 of 12 benchmark–backbone settings across code generation, tool use, and search-QA. Its overall scores reach 51.21% with Qwen3-4B and 59.95% with Qwen3-8B, surpassing the strongest baseline by 6.06% and 3.91%, respectively. On retrieval-intensive tasks, it improves F1 by an average of 5.20% on 2Wiki across backbones and by 6.38% on HotpotQA with Qwen3-8B. Using accumulated execution feedback, the Meta-Agent identifies Task-Agent bottlenecks and selects Model, Harness, or Artifacts workflows. It distills successful and unsuccessful outcomes into reusable skills and principles to evolve its Meta-Harness. Across six benchmarks and two backbones, RSIFlow outperforms the strongest evaluated baseline in 11 of 12 settings. Ablations validate both mechanisms, while budget analyses show a favorable performance–budget trade-off. These results demonstrate that continual Meta-Agent evolution enhances system effectiveness alongside adaptive workflow orchestration. Limitations RSIFlow is primarily evaluated using Qwen3-4B and Qwen3-8B as Task-Agent backbones. This setting is particularly relevant to resource-constrained agent deployments, where adaptive workflow orchestration enables targeted modifications to identified bottleneck components, while Meta-Agent evolution further improves bottleneck diagnosis and orchestration capabilities. However, whether these benefits remain significant with larger backbone models and at cluster scale remains unexplored. Future work will extend the evaluation to larger-scale settings to assess the scalability of RSIFlow. RSIFlow couples the Task-Agent and Meta-Agent, evolving the Meta-Harness through reusable skills and general principles to improve workflow orchestration without updating the Meta-Agent’s model parameters. However, this process introduces additional computational overhead, while adopting a lower-cost Meta-Agent may compromise evolution gains. Moreover, the stability of experience-driven Meta-Harness updates remains to be fully investigated. Future work will explore counterfactual analysis to identify Meta-Agent deficiencies, apply targeted local modifications, and investigate Meta-Agent parameter optimization to improve evolution efficiency and stability. BFCL-v3 evaluates function selection and argument construction in single-call, multiple-call, parallel-call, relevance, and multi-turn settings ( Patil et al., 2025 ) . The distinction matters because one task can contribute more than one native scoring record. Record-level scoring describes the evaluator’s individual scoring units, whereas complete-task success summarizes outcomes at the original task level. We therefore specify both task and scoring-record counts when describing this evaluation. Multi-hop question answering. B.2 Workflow Orchestration The Meta workflow connects six operations: evidence collection, diagnosis, skill retrieval, component intervention, paired evaluation, and skill integration. Diagnosis returns a bottleneck hypothesis with trajectory references; retrieval returns applicable procedures and counterexamples; intervention returns a candidate and its change record; evaluation returns paired outcomes; integration returns the next active skill set and the Action changes needed to use it. A decision record binds the selected component to its expected behavioral effect and preservation constraints before construction. The Model branch receives eligible trajectories and a training configuration; the Harness branch receives a localized modification brief and interface contract; the Artifacts branch receives the Task’s own output and permitted feedback. Evaluation determines Task acceptance, while the entire record informs Meta evolution. An accepted Task change and a revised Meta procedure are thus separate decisions within the same loop. Recent work on LLM agents explores approaches to adapting execution structures, maintaining persistent memory, and coordinating information acquisition. HarnessForge ( Chen et al., 2026b ) jointly evolves execution harnesses and reasoning policies through failure-guided harness modification and harness-conditioned policy alignment. For persistent memory, All-Mem ( Lv et al., 2026a ) separates online retrieval from offline topology consolidation, preserving evidence while supporting retrieval under bounded computational budgets. Typed links enable budgeted expansion from anchors to archived evidence. For breadth-oriented information gathering, moreover, A-MapReduce ( Chen et al., 2026c ) decomposes wide-search objectives into parallel retrieval tasks and aggregates results, using experiential memory to refine task allocation and recomposition. These approaches improve how agents organize execution and retain or acquire information, with emphases on system compatibility, memory maintenance, and scalability. Structured Supervision and Credit Assignment. A complementary line of research studies the structure and granularity of supervision for agent learning and language model post-training. GEAR ( Lv et al., 2026b ) models prerequisite and activation dependencies among rubric criteria with a probabilistic graphical framework, suppressing unsupported criterion contributions when constructing scalar rewards. The resulting reward captures criterion dependencies at the response level. For long-horizon agent distillation, AlignOPSD ( Chen et al., 2026a ) aligns privileged supervision with functionally corresponding decisions and distributes outcome-based credit across variable-duration decision spans and their constituent turns. TRCA ( Zhang et al., 2026a ) derives step-level supervision from action-induced state transitions using Evidence, Execution, and Invalidity rubrics. Its foundational reward evaluates local transition quality, while its breakthrough reward recognizes newly satisfied task conditions, providing fine-grained learning signals without requiring successful reference trajectories or learned process evaluators, even when terminal success feedback is sparse.
