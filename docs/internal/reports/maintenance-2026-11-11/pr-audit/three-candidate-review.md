# 三篇新候选独立范围与摘要复核

- **SciMARS：建议 harness/evolve_main。** 编辑角色程序、交接契约和记忆策略，公开执行探针决定保留版本；只跨同任务后续改进轮保留，新评测任务重置，改进器固定。科学发现结果来自数据回放和数字孪生，不是新做实体湿实验。
- **JoMoHa：建议 harness/coevolution，secondary model_weights。** 两模型训练之外有执行反馈生成的可执行代码、验证、保存和部署复用；固定 Solver 对比已保存程序支撑外部代码工件的作用。不能据此声称部署时持续自改，也不声称每轮继承上轮源码。
- **SMO：建议排除 Harness RSI。** 编译缺口与结构准入驱动技能库更新，正文明确 Agent 执行不回流。任务评估并未成为继续修改工件的反馈，不把离线编译复用称为执行反馈自进化。

数据问题：SMO 官方 Atom 元数据把 token reduction 写为倍数，而官方 HTML 摘要及正文写百分比。两份原文与哈希均保留，仅报告，不修改数值。摘要不使用该数字。

三篇定性双语摘要数字守卫全部通过，原始身份、日期、摘要与官方元数据一致，全部正文引文有 DOM 定位与字节哈希。仅对引用段落、方法协议及范围做复核，未重跑实验或全表复算。没有新来源请求、没有付费调用、没有 production/Git/GitHub 修改；本文件不是正式批准或发布证明。
